# Architecture Decision Records

One file per decision, numbered in order. An ADR is never edited after it is
accepted; a later ADR supersedes it instead.

| Status     | Meaning                                                 |
| ---------- | ------------------------------------------------------- |
| Proposed   | Under discussion. Do not build on it yet                |
| Accepted   | Decided. Code and data must follow it                   |
| Superseded | Replaced by a later ADR, linked from the superseded one |
