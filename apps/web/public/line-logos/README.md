# Line logos

Operator and line logos, used only to identify each line next to its name
(nominative use). They are trademarks of their operators; showing them does
not imply any endorsement of this project.

All files are unmodified downloads of the originals linked below, which were
marked public domain when downloaded (2026-10-17). The MRT and BTS logos are
also tagged "trademarked" on Commons.
